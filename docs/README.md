# Банковские вклады

Учебный проект: автоматизация учёта видов вкладов, клиентов банка и открытых ими счетов.

## 1. Исходное описание предметной области

Банк предлагает клиентам размещать денежные средства на срочных вкладах различных видов:

| Наименование вклада | Срок хранения (мес.) | Ставка, % годовых |
| --- | --- | --- |
| Накопительный | 13 | 10 |
| Капитал | 18 | 7 |
| Победа | 13 | Ставка рефинансирования + 2 |
| К отпуску | 12 | Ставка рефинансирования + 1 |

Необходимо организовать учёт видов вкладов, клиентов и открытых ими счетов, чтобы
анализировать работу банка с вкладами.

Следует учитывать:

- один клиент может открыть несколько счетов;
- каждый счёт открывается одним клиентом;
- один вид вклада может использоваться для нескольких счетов;
- каждый счёт открывается по одному виду вклада;
- клиент может иметь несколько счетов, но каждый счёт обязательно принадлежит клиенту;
- отдельный вид вклада может временно не использоваться клиентами.

## 2. Краткое описание (выделение ключевых сущностей)

### 2.1. Вид вклада (`Deposit`)

| Свойство | Тип данных |
| --- | --- |
| код вклада (UUID) | `Uuid` |
| наименование вклада | `String` |
| срок хранения (мес.) | `i32` |
| ставка, % годовых | `f32` |
| дата создания | `UtcDateTime` |
| дата обновления | `Option<UtcDateTime>` |
| дата удаления | `Option<UtcDateTime>` |

### 2.2. Клиент (`Client`)

| Свойство | Тип данных |
| --- | --- |
| код клиента (UUID) | `Uuid` |
| Ф.И.О. | `String` |
| номер паспорта (уникальный) | `String` |
| адрес | `String` |
| телефон (уникальный) | `String` |
| дата создания | `UtcDateTime` |
| дата обновления | `Option<UtcDateTime>` |
| дата удаления | `Option<UtcDateTime>` |

### 2.3. Счёт (`Account`)

| Свойство | Тип данных |
| --- | --- |
| № счёта (UUID) | `Uuid` |
| код клиента (UUID, внешний ключ) | `Uuid` |
| код вклада (UUID, внешний ключ) | `Uuid` |
| дата открытия счёта | `UtcDateTime` |
| дата закрытия счёта | `Option<UtcDateTime>` |
| сумма вложенная (руб.) | `f32` |
| дата создания | `UtcDateTime` |
| дата обновления | `Option<UtcDateTime>` |
| дата удаления | `Option<UtcDateTime>` |

## 3. Связи между сущностями

- `clients` 1 — N `accounts` (у клиента может быть несколько счетов, счёт всегда принадлежит клиенту);
- `deposits` 1 — N `accounts` (вид вклада может использоваться во многих счетах и может временно не использоваться вовсе);
- `accounts` — связующая сущность между клиентом и видом вклада.

Внешние ключи заданы в миграции `migrations/*_accounts_initial.sql`
(`clients_fk`, `deposits_fk`).

## 5. HTTP API

| Метод | Маршрут | Действие |
| --- | --- | --- |
| `POST` | `/deposits` | добавить вид вклада |
| `GET` | `/deposits/:id` | получить вид вклада |
| `PUT` | `/deposits/:id` | изменить вид вклада |
| `DELETE` | `/deposits/:id` | удалить вид вклада |
| `POST` | `/clients` | добавить клиента |
| `GET` | `/clients/:id` | получить клиента |
| `PUT` | `/clients/:id` | изменить клиента |
| `DELETE` | `/clients/:id` | удалить клиента |
| `POST` | `/accounts` | открыть счёт |
| `GET` | `/accounts/:id` | получить счёт |
| `PUT` | `/accounts/:id` | изменить счёт |
| `DELETE` | `/accounts/:id` | удалить счёт |

Сервер слушает `http://localhost:3000`, запуск: `cargo run`.

## 6. Стек

- Rust 2021, `ohkami` 0.24 (HTTP-сервер, `rt_smol`), `smol`;
- `async-sqlite` + `rusqlite` (SQLite), `async-lock`;
- `uuid` (идентификаторы), `time` (даты), `serde` / `serde_json` (JSON).
